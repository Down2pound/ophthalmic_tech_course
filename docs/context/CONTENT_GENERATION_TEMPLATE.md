# Content Generation Template

Use this template whenever a person or AI system creates or revises an
OptiTech Academy lesson, quiz, scenario, job aid, or communication.

```text
AUTHORITATIVE CONTEXT
Follow docs/context/COURSE_CONTEXT.md and the applicable record in
docs/context/MODULE_CONTEXTS.md. When information conflicts, use the priority
order in COURSE_CONTEXT.md.

TASK
[State exactly what should be created or revised.]

LEARNER
[Describe what the learner already knows and has completed.]

LEARNING OBJECTIVES
1. [Observable objective]
2. [Observable objective]
3. [Observable objective]

APPROVED FACTS AND SOURCES
- [Fact or source]
- [Fact or source]

PRACTICE-SPECIFIC CONTEXT
[State the applicable policy or write "None supplied." Never invent one.]

REQUIRED OUTPUT
- [Required sections]
- [Length or format]
- [Number and type of questions]
- [Job aid or competency checklist requirements]

MUST INCLUDE
- Beginner-friendly definitions
- Clinical-role boundaries
- Common mistakes
- Stop, repeat, or escalate guidance
- Knowledge-check explanations
- Supervisor validation for hands-on skills

MUST AVOID
- PHI or identifiable patient details
- Unsupported clinical claims
- Diagnosis or independent treatment decisions
- Invented device settings, thresholds, or practice policies
- Claims that course completion equals certification or hands-on competency

QUALITY CHECK
Evaluate the draft against docs/context/QUALITY_CHECKLIST.md. Repair every
failure that can be corrected from the supplied sources. Clearly flag anything
requiring clinical or practice-leadership review.
```

## Example request

```text
TASK
Create an entry-level lesson on measuring distance visual acuity.

LEARNER
The learner completed Module 1 but has not performed visual-acuity testing.

LEARNING OBJECTIVES
1. Explain the purpose of distance visual-acuity testing.
2. Describe a safe, repeatable testing sequence.
3. Record a Snellen result and recognize when to repeat or escalate.

APPROVED FACTS AND SOURCES
- Use only the supplied practice protocol and clinical-review notes.
- If a required procedural detail is absent, flag it instead of guessing.

REQUIRED OUTPUT
- Standard lesson contract
- Five multiple-choice questions with answer explanations
- One patient communication script
- One supervisor-observed competency checklist
```
